# Candidatures — Raphaëlle Rath

Suivi de recherche d'emploi : Marketing Manager / Project Manager, secteurs beauté &
cosmétiques, édition/livres, voyage. Cibles géographiques : UK, Pays-Bas, Suède, Norvège.

## Structure

- `profil.md` — résumé du profil utilisé pour matcher les offres et rédiger les candidatures.
- `candidatures/tracking.md` — tableau de suivi de toutes les offres shortlistées (statut, lien, notes).
- `candidatures/entreprises_sponsors_uk.md` — liste d'entreprises UK des secteurs cibles
  confirmées "licensed sponsor" sur le registre officiel Home Office, pour prioriser
  candidatures spontanées et veille sur leurs portails carrière.
- `cv_lettres/` — lettres de motivation adaptées par offre ou groupe d'offres, prêtes à copier-coller.

## Workflow

Ce repo ne soumet **aucune candidature automatiquement**. Chaque offre listée dans
`candidatures/tracking.md` inclut un lien direct — Raphaëlle valide et clique elle-même
pour postuler. Les lettres de motivation dans `cv_lettres/` sont des brouillons à relire
avant envoi.
